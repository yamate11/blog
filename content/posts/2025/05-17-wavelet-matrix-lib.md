Wavelet 行列ライブラリを書いた．

## 使用法

```cpp
vector<ll> vec{...};
WaveletMatrix wm(vec);
cout << wm.kth_rank(10, 20) << endl;
```

### コンストラクタ

```cpp
WaveletMatrix wm(vec, amax);
```

* vec ... データを格納したベクトルなど．すべて非負整数であることが必要．
* amax ... 「データがこの値を超えない」という値．`-1` (省略値) を指定すると，ライブラリの方で最大値を取ってくれる．

### データメンバ

* `wm.N` ... データの個数

他にもあるが，使わないと思う．

### データ値の取得

```cpp
wm.access(i);
```

i 番目の値を取得する．`vec[i]` と同じになるはずなので，あまり使い途はない．

### 出現回数 (指定値)

```cpp
wm.rank(t, r);
wm.rank(t, l, r);
```

* 値 `t` が現れる回数を返す．
    * 上の呼出については，区間 `[0, r)` に `t` が現れる回数．
    * 下の呼出については，区間 `[l, r)` に `t` が現れる回数．
* `t` が負の時には (そういうものは現れ得ないから) 0 を返す．
* `[0, r)` や `[l, r)` の `[0, wm.N)` の外にある部分は無視される．
* `wm.range(t, t + 1, l, r)` と同じ値になる (が，こちらが基本なので残してある)．

### k番目

```cpp
wm.kth_smallest(k, l, r);
wm.kth_largest(k, l, r);
```

* 区間 `[l, r)` で，`k` 番目に小さい / 大きい 値を返す．
* `k` は 0-indexed.  たとえば最小値は `kth_smallest(0, l, r)`.
* `[l, r)` の `[0, wm.N)` の外にある部分は無視される．
* `k` は意味がある値でなければならない．つまり，普通は `0 <= k < r - l` が必要．
  範囲指定が怪しいときには `0 <= k < min(wm.N, r) - max(l, 0)` が必要．

### 出現回数 (指定範囲)

```cpp
wm.range_freq(hi, l, r);
wm.range_freq(lo, hi, l, r);
```

* 区間 `[l, r)` において次を満たす要素 t の個数を返す．
  * 上の呼出については，`t < hi`
  * 下の呼出については，`lo <= t < hi`
* `[lo, hi)` と `[0, amax)` の共通部分が無いときには 0 を返す．たとえば `[-10, -1)` や `[7, 3)` など．
* `[l, r)` と `[0, wm.N)` の共通部分が無いときには 0 を返す．
